# 📱 SpeakFlow Support Guide

---

## 📱 About SpeakFlow

SpeakFlow is a language learning app that helps you practice real-life conversations.

Using speech recognition technology, you can practice speaking out loud and learn practical expressions through various scenarios that you can use immediately in real life.

### ✨ Key Features

- **🎤 Speech Recognition-Based Learning**: Practice by actually speaking
- **📚 Diverse Scenarios**: Real-life situations including daily life, travel, and business
- **🤖 AI Conversation Partner**: Support for free conversation practice
- **🎯 Personalized Learning**: Create your own scenarios
- **🌍 Multilingual Support**: Korean, English, Japanese, Chinese, Spanish, Indonesian

---

## 🎯 How to Use

### 1️⃣ Select Learning Mode

SpeakFlow offers three learning modes:

#### 🗣️ Free Conversation
- Converse freely with AI
- No fixed script, talk about any topic
- Effective for improving practical conversation skills

#### 📖 Scenario Practice
- Learn conversation patterns organized by situation
- Various scenarios including restaurants, airports, shopping
- Systematic learning that progresses step by step

#### 🎙️ Pronunciation Practice
- Training focused on sentence pronunciation
- Acquire accurate pronunciation through repetition
- Improve confident speaking skills

### 2️⃣ Select Scenario

#### Built-in Scenarios
- 53 scenarios organized by category
- Various difficulty levels from beginner to advanced
- Focused on frequently used expressions in real life

#### Create Your Own Scenarios
1. Click the `+` button on the main screen
2. Choose one of two methods:
   - **Write Directly**: Enter conversation content yourself
   - **AI Generation**: AI automatically generates based on the situation you input

### 3️⃣ Start Conversation

1. **Check Sentence**: Read the learning sentence displayed on screen
2. **Tap Microphone**: Press the microphone button when ready
3. **Speak**: Say the sentence out loud
4. **Feedback**: The app automatically recognizes and shows results

### 4️⃣ Speech Recognition

- **Automatic Recognition**: Real-time recognition of what you say
- **Flexible Matching**: Punctuation differences are ignored
- **Immediate Feedback**: Check accuracy instantly

### 💡 Useful Tips

#### Speech Recognition Tips
- Practice in a quiet environment
- Speak close to the microphone
- Pronounce clearly
- Don't worry about punctuation (commas, periods, question marks are automatically ignored)

#### Effective Learning Methods
- **Preview Script**: Check the entire conversation with the script viewer button before starting
- **Repeated Practice**: Practicing the same scenario multiple times helps expressions become natural
- **Various Scenarios**: Practice scenarios from different situations evenly
- **Consistent Learning**: Practicing a little every day is most effective

## ❓ Frequently Asked Questions (FAQ)

### Q1: Voice recognition isn't working well

**A:** Please check the following:
- Are you using it in a quiet environment?
- Is microphone permission granted?
- Are you speaking clearly close to the microphone?
- Punctuation differences are ignored, so it works if the content matches

### Q2: I want to create scenarios

**A:** There are two ways to create scenarios:

#### Method 1: Create Directly
1. Click `+` button on main screen
2. Select "Create Scenario" tab
3. Enter title, description, icon
4. Add conversation turns and write content
5. Can add multiple choices for each turn

#### Method 2: Generate with AI
1. Click `+` button on main screen
2. Select "Import JSON" tab
3. Generate GPT prompt with the generate prompt button
4. Paste into ChatGPT to receive JSON
5. Paste received JSON into app

**Tip**: JSON copied from Notion or notes apps is automatically converted and usable!

### Q3: How is pronunciation evaluated?

**A:** The current version only checks sentence matching. It checks if what you said matches the correct sentence and provides feedback.

The following features will be added in future updates:
- Pronunciation accuracy evaluation
- Intonation and stress analysis
- Improvement point suggestions

### Q4: What languages can I learn?

**A:** Currently supports 6 languages:
- 🇰🇷 Korean
- 🇺🇸 English
- 🇯🇵 Japanese
- 🇨🇳 Chinese
- 🇪🇸 Spanish
- 🇮🇩 Indonesian

53 basic scenarios are provided for each language.

### Q5: How is data stored?

**A:**
- All data is stored locally on the device
- Not uploaded to the cloud
- Privacy is thoroughly protected
- Conversation history is only viewable within the app

### Q6: Can I use it offline?

**A:**
- **Scenario Practice**: Available offline (except speech recognition)
- **Speech Recognition**: Requires internet connection
- **AI Conversation**: Requires internet connection
- **Scenario Creation**: Requires internet connection (when using GPT)

### Q7: Can I view conversation history?

**A:** Yes! Tap the clock icon (🕐) on the main screen to view all your conversation history.
- Conversation list organized by date
- Can check detailed content of each conversation
- Use for review

## 🛠️ Troubleshooting

### When Voice Recognition Doesn't Work

1. **Check Microphone Permission**
   - Settings > SpeakFlow > Allow Microphone Permission

2. **Check Internet Connection**
   - Speech recognition requires internet connection

3. **Restart App**
   - Completely close and restart the app

### When Scenarios Don't Load

1. **Restart App**
2. **Reset Settings** (Settings > Reset button)
3. **Reinstall App** (after backing up data)

### JSON Import Error

**Error Message**: "Invalid JSON format"

**Solution**:
- Check if JSON format is correct
- Check if using regular quotes (" ") not smart quotes (" ") (automatically converted)
- Remove trailing commas (,)
- Confirm you copied the entire JSON generated by GPT

## 🎓 Learning Guide

### Roadmap for Effective Learning

#### Stage 1: Building Foundation (1-2 weeks)
- Start with basic greeting scenarios
- Get familiar with pronunciation practice mode
- Practice consistently for 10-15 minutes daily

#### Stage 2: Practical Practice (3-4 weeks)
- Focus on daily life scenarios
- Repeat same scenario 3+ times
- Challenge speaking without looking at script

#### Stage 3: Application and Expansion (5 weeks~)
- Challenge travel and business scenarios
- Utilize free conversation mode
- Create and practice your own scenarios

### Learning Goal Examples

#### Beginner
- Master 5 basic greeting scenarios perfectly
- Achieve 70%+ pronunciation accuracy
- Practice 10 minutes daily

#### Intermediate
- Master 15 daily conversation scenarios
- Progress conversation without script
- Hold 10+ minute conversations in free mode

#### Advanced
- Experience all category scenarios
- Create 3+ custom scenarios
- Natural conversation even in complex situations
